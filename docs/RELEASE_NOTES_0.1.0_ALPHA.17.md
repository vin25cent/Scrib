# Scrib 0.1.0-alpha.17

Build de développement destiné aux essais sur Apple Silicon.

## Évolutions

- ajout de l’action **Ouvrir le dossier dans Finder** dans le détail d’un cours du **Suivi des cours** ;
- accès direct au dossier local racine du cours sélectionné, avec ses audios, manifestes et transcriptions ;
- résolution du stockage via `FileManager` et le `CourseID`, sans chemin macOS absolu codé en dur ;
- création de la racine officielle du cours lorsqu’elle n’existe pas encore.

## Important

- cette version reste en développement / alpha ;
- l’archive est signée ad hoc et non notarée.
