# Scrib 0.1.0-alpha.9

Build expérimentale destinée aux essais sur Apple Silicon.

## Évolutions

- les commandes d’enregistrement, de transcription et de téléchargement sont protégées contre les actions simultanées et les retours tardifs ;
- les sessions d’enregistrement et leurs segments sont maintenant persistés localement pour pouvoir être récupérés après une interruption.

## Important

- cette version reste en développement / alpha ;
- l’archive est signée ad hoc et non notarée.
