# Décisions ouvertes

Ces choix ne doivent pas être devinés avant les prototypes ou l'arrivée du Mac.

| Décision | Méthode | Moment |
|---|---|---|
| Version minimale exacte de macOS | Vérifier la version livrée sur le Mac | Réception |
| Moteur et modèle de transcription | Benchmark fidélité/RAM/impact Word | Phase 3 |
| Stratégie de réduction du bruit | Test micro interne avec frappe réelle | Phase 1 |
| Diarisation | Mesurer enseignant/étudiants en amphithéâtre | Phase 3 |
| Fournisseur et modèle cloud | Comparatif plafonné à 10 € | Phase 4 |
| Budget mensuel courant | Mesurer le coût sur une semaine puis extrapoler | Phase 4 |
| Domaines autorisés précis | Valider HAS, ANSM, SPF, UE, OMS, NICE, CDC et sous-domaines | Phase 5 |
| Palette et modèle Word final | Comparer deux ou trois rendus dans Word/iPhone | Phase 4 |
| Intitulé de l'UE 5.7 optionnelle | Compléter la valeur lorsque l'IFSI la communiquera | Phase 1 |
| Signature/notarisation | Commencer gratuitement, réévaluer après la recette | Phase 6 |

## Éléments manquants

WhisperKit 1.0.0 est seulement le premier adaptateur expérimental de l’alpha.2.
Ni sa compatibilité pratique avec le M1 cible, ni Tiny, ni Small ne sont encore
validés comme choix final avant les mesures réelles.

- la maquette PNG créée dans la conversation d'origine n'est pas jointe à ce
  dépôt ; elle devra être ajoutée à `docs/mockups/` ;
- aucun audio réel ni support enseignant ne doit être ajouté au dépôt public ;
- les jeux de tests médicaux devront provenir de conférences publiques dont le
  droit de réutilisation a été vérifié.
